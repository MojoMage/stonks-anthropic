# stonks-anthropic

A private, password-protected page for Stonks Fund limited partners.

The page content is stored encrypted in `content.js` and is decrypted in the browser with the password. The other files are the page shell, styles and the D3 charting library (v7, ISC licence).

Published with GitHub Pages from `main` / root: https://mojomage.github.io/stonks-anthropic/
